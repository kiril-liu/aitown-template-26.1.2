# AI Town

AI Town 是一个基于 **Minecraft 26.1.2 / NeoForge 26.1.2.61-beta** 的智能小镇 Mod 原型。

## 当前功能
### 小镇系统芯片
 Town System Chip  是当前统一入口。
已支持：
•  Shift + 右键方块 
• 设置小镇中心
• 同时设置小镇仓库中心
•  Shift + 右键村民 
• 将村民注册为智能村民
• 循环切换职业：
• 建筑师
• 伐木工
• 矿工
•  右键智能村民 
• 查看该村民当前状态
当前版本暂未实现 GUI，小镇状态面板计划先用聊天栏信息输出。
### 智能村民系统
每个智能村民会记录：
• 名字
• ID
• 职业
• 当前状态
• 当前任务
• 小镇中心
• 仓库中心
• 背包物品
### 智能村民身份管理
• 职业记录
• 状态显示
• 小镇中心 / 仓库中心记录
• 村民移动目标
• 仓库存取物品
• 掉落物扫描与拾取
• 建筑放置安全检查
### 建筑师
• 自动寻找可建造空地
• 根据蓝图尺寸计算建筑占地
• 站在门口附近施工
• 从小镇仓库取建筑材料
• 分 tick 放置方块
• 放置前检查目标位置是否安全
• 建完一栋房子后继续寻找下一块空地
### 伐木工
• 寻找附近成熟树木
• 走到树旁
• 分 tick 砍树
• 清理树周围掉落物
• 收集原木、树苗、苹果、木棍
• 在砍树位置补种树苗
• 没有树苗时会去仓库取树苗
• 背包产物达到阈值后存入小镇仓库
• 等待树苗长大或继续寻找下一棵树
### 矿工
• 寻找自然岩体中的石头
• 只采集小镇中心高度或以上的石头
• 不向地下开采
• 过滤附近有人造建筑方块的石头
• 走到石头旁边
• 破坏石头并生成掉落物
• 收集圆石等石材产物
• 达到指定数量后存入小镇仓库
### 小镇仓库
当前小镇仓库不是独立方块，而是：小镇中心附近一定范围内的箱子集合
工人通过  SmartVillagerData  中的公共方法与仓库交互：
• 从仓库取物品
• 向仓库存物品
目前仓库用于：
• 伐木工存入木材、树苗、苹果、木棍
• 矿工存入圆石和其它石材
• 建筑师取出木材和石材建房
当前已知限制
• 小镇状态面板方法已存在，但右键空气入口还需要接入。
• 背包查看逻辑目前仍兼容旧字段，后续应统一改为  SmartRole  判断。
• 暂无真正 GUI。
• 暂无经济系统。
• 暂无金币结算。
• 暂无生活开销。
• 暂无农民职业。
• 矿工当前只做地表采石，不下矿洞。
• 建筑师当前使用原版结构蓝图，并将复杂材料简化为木材 / 石材体系。
## 开发计划
### 短期目标：
• 接入小镇芯片右键空气状态面板
• 将旧的  IsBuilding  /  IsLumberjack  判断统一为  SmartRole 
• 稳定建筑师、伐木工、矿工三个职业闭环
• 优化仓库存取逻辑
• 让建筑师更好地消费矿工产出的石材
### 中期目标：
• 新增农民职业
• 新增更完整的小镇仓库系统
• 新增交易价值表
• 新增金币系统
• 新增工人生活开销
### 长期目标：
• 小镇居民拥有职业、收入、消耗、住房需求和协作关系
• 多工种共同推动小镇扩张
• 建立可解释、可扩展、可玩的智能小镇系统
