# AI Town - 智能村民 Mod (Smart Villagers)
AI Town Mod 是一个基于 Minecraft Java Edition / NeoForge 的智能小镇实验项目。项目目标是构建一个能逐步成长的小镇模拟系统，让智能村民拥有职业、状态、仓库交互、生产行为、基础生活需求和日记记录。
## 当前定位
当前版本已经实现一个可运行的小型智能小镇原型，核心循环已从“单个智能村民行为”推进到“小镇生产系统”。
已包含：
- 小镇芯片系统
- 智能村民职业系统
- 仓库中心系统
- 职业生产链
- 基础经济系统
- 饥饿值系统
- 日记系统
- 可点击聊天详情
- 基础住房材料生产链
## 已实现功能
### 小镇芯片系统
小镇芯片是系统的统一入口，玩家需要手持小镇芯片进行交互。
使用方式：
- **Shift + 右键点击村民**：注册智能村民，或打开村民职业选择相关操作。
- **右键点击村民**：查看该村民的详细信息，包括职业、状态、金币、饥饿值和日记等。
- **Shift + 右键点击地板**：设置小镇中心和仓库中心位置。
- **手持芯片时 Shift + 右键天空**：查看小镇内所有智能村民的状态。
- **手持芯片时右键天空**：查看仓库流水记录和当前仓库信息。
当前设计中，小镇中心和仓库中心暂时使用同一个位置。
### 智能村民职业
当前已实现以下职业：
- **建筑工**：寻找建造区域，根据蓝图建房，从仓库取材料，建造门和床，并在完成后写入日记。
- **伐木工**：寻找树木，砍伐原木，清理树叶，拾取掉落物，补种树苗，并将木材、树苗、苹果、木棍等存入仓库。
- **采石工**：开采圆石、石头、煤炭等基础资源，拾取掉落物，并存入仓库。
- **工匠师**：在工坊检查仓库需求，取出原料，生产商品，并将成品送回仓库。
- **农田工**：以工作点为农田中心，开垦土地，种植、收割小麦，并将小麦存入仓库。
- **牧羊工**：以工作点为牧场中心，搭建 7x7 牧场，引导羊进入牧场，剪羊毛并存入仓库。
### 仓库系统
仓库是小镇的资源中心，所有职业都围绕仓库进行存取。
当前仓库识别：
- 箱子
- 木桶
仓库记录支持：
- 最近 20 条全局流水
- 中文物品名称显示
- 存入 / 取出记录
- 当前仓库剩余数量显示
### 基础经济系统
- 村民把资源或商品存入仓库后，可以根据固定价格获得金币。当前价格表主要用于调试和观察，后续可扩展为动态价格、供需变化、消费、房屋购买、村民交易和职业工资系统。
### 饥饿值系统
- 智能村民拥有基础饥饿值。饥饿值会随时间上升，过高时会中断当前工作，并前往仓库寻找苹果。当前食物系统仍较简单，主要用于验证“生活需求可以打断职业行为”。
### 日记系统
- 智能村民会记录阶段性行为，例如建筑工完成房屋、伐木工砍伐树木、采石工开采石材、工匠师生产商品、农田工完成农作、牧羊工收集羊毛等。日记可通过聊天中的详情按钮查看。

## 长期目标
AI Town Mod 的长期目标是构建一个有生活感的小镇模拟系统。未来的小镇居民将不只是执行固定任务的机器，而是拥有职业、饥饿、住所、记忆、经济、日记、社交、需求和行为选择。
最终目标是让每个智能村民都能在 Minecraft 世界中拥有自己的生活轨迹。
